# ระบบลงเลขหนังสือ — แอป (PWA)

เปลือกแอปสำหรับติดตั้ง **ระบบลงเลขหนังสือ** (Google Apps Script) ลงหน้าจอโฮมของมือถือและคอมพิวเตอร์
เมื่อติดตั้งแล้ว แอปเปิดแบบเต็มจอ มีไอคอนของตัวเอง และไม่ต้องหาลิงก์ทุกครั้ง

ข้อมูลและการออกเลขยังทำงานบน Apps Script และ Google Sheets ของโรงเรียนเหมือนเดิม แอปนี้แค่เปิดเว็บแอปไว้ในกรอบเต็มจอ

## โครงสร้าง

| ไฟล์ | หน้าที่ |
|---|---|
| `config.js` | **ไฟล์เดียวที่ต้องแก้** — ใส่ URL เว็บแอป Apps Script |
| `index.html` | หน้าแอป: หน้าเริ่มโหลด, หน้าออฟไลน์, ปุ่มแนะนำติดตั้ง |
| `manifest.webmanifest` | ชื่อ ไอคอน และสีของแอป |
| `sw.js` | Service worker เก็บเปลือกแอปไว้ในเครื่อง ให้เปิดเร็วและแสดงหน้าออฟไลน์ได้ |
| `icons/` | ไอคอนแอปทุกขนาด |

## ตั้งค่า (ครั้งเดียว)

1. **Apps Script**: การทำให้ใช้งานได้ → จัดการ → คัดลอก **URL เว็บแอป** (ลงท้ายด้วย `/exec`)
   - ผู้มีสิทธิ์เข้าถึงต้องเป็น **ทุกคน**
2. แก้ `config.js` แล้ววาง URL ที่ `APP_URL`
3. **GitHub**: Settings → Pages → Source: **Deploy from a branch** → Branch: `main` / `(root)` → Save
4. รอประมาณ 1 นาที แอปจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

## วิธีติดตั้งบนเครื่อง (ส่งให้ครู)

- **Android (Chrome)**: เปิดลิงก์ → กดปุ่ม **ติดตั้ง** ที่ขึ้นด้านล่าง (หรือเมนู ⋮ → *ติดตั้งแอป*)
- **iPhone / iPad**: เปิดลิงก์ใน **Safari** → ปุ่มแชร์ ⬆️ → **เพิ่มไปยังหน้าจอโฮม**
- **คอมพิวเตอร์ (Chrome / Edge)**: กดไอคอนติดตั้ง ⊕ ที่แถบที่อยู่

> ถ้าเปิดลิงก์จาก LINE ให้กด ⋯ → *เปิดในเบราว์เซอร์* ก่อน แล้วจึงติดตั้ง

## เมื่ออัปเดตโค้ด Apps Script
ไม่ต้องแก้อะไรในแอปนี้ ถ้า Deploy แบบ *จัดการ → แก้ไข → เวอร์ชันใหม่* URL จะยังเหมือนเดิม
ถ้าสร้าง Deploy ใหม่จน URL เปลี่ยน ให้แก้ `config.js` แล้ว commit

ถ้าแก้ไฟล์ในแอปนี้ (เช่น ไอคอน) ให้เปลี่ยน `CACHE` ใน `sw.js` เป็นเวอร์ชันใหม่ เช่น `docnum-shell-v2` เพื่อให้เครื่องที่ติดตั้งไว้ได้ไฟล์ใหม่

## ข้อจำกัด
- ใช้งานออฟไลน์ไม่ได้ เพราะการออกเลขต้องเชื่อมกับ Google Sheets เพื่อไม่ให้เลขซ้ำ แอปจะแสดงหน้าแจ้งเตือนเมื่อไม่มีอินเทอร์เน็ต
- ไม่มีการแจ้งเตือนแบบ push ระบบแจ้งผู้รับงานทางอีเมลเหมือนเดิม
